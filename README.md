# Дом

Экшен-рогалик с видом сверху. Веб в первую очередь, Android и iOS из той же кодовой базы.

Документы проекта:

- [BRIEF.md](BRIEF.md) — вопросы, с которых всё началось
- [CONCEPTS.md](CONCEPTS.md) — три рассмотренных концепта и обоснование выбора
- [GDD.md](GDD.md) — дизайн-документ: мир, механики, дорожная карта

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

```bash
npm run build      # проверка типов и продакшен-сборка в dist/
npm run typecheck  # только проверка типов
```

## Управление

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Движение | WASD | левый стик |
| Прицел | мышь | правый стик |
| Серия ударов | ЛКМ | X |
| Тяжёлый удар | ПКМ, удержать | Y, удержать |
| Рывок | Пробел | A |

Главное правило боя: **рывок отменяет откат после удара**. На этом строится вся боевая
система, всё остальное это следствия.

## Устройство кода

```
src/
  config/GameConfig.ts     все настраиваемые числа, единственный источник правды
  input/                   ввод устройств сводится к одному InputIntent
  core/                    обратная связь: заморозка, тряска, вспышка, цифры урона
  combat/                  попадания по дуге, эффект взмаха, интерфейс цели
  entities/                игрок, манекен, полоса здоровья
  scenes/                  генерация плейсхолдер-текстур и тестовая арена
```

Два правила, на которых держится структура:

1. **Один класс — один файл, одна ответственность.** Игрок не вызывает тряску камеры,
   он сообщает о попадании. Подача остаётся заботой сцены.
2. **Числа не живут в коде поведения.** Ощущение боя настраивается правкой
   `GameConfig.ts`, а не правкой классов.

## Про анимацию

В проекте нет и не будет покадровой анимации персонажей. Движение собирается кодом:
твины смещения, растяжение и сжатие, рывок масштаба. Взмах это отдельный спрайт дуги,
который прочерчивается и гаснет. Подробнее в разделе 2 [GDD.md](GDD.md).

Причина простая: ИИ отлично генерирует статичную картинку и плохо генерирует связный
набор кадров. Мы строим пайплайн вокруг того, что работает.
